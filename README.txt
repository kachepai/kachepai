KachePai — কাছেপাই
===================
ডেমো e-commerce starter website.

যা আছে:
- বাংলা সহজ UI
- Search + voice search (browser support থাকলে)
- Category filter
- Product cards
- Stock/price দেখানো
- Cart + wishlist
- Buy Now
- Simple checkout
- COD, bKash, Nagad, Rocket, Upay, Card, Send Money, Bank options
- Settings/Admin demo: দোকানের নাম, slogan, logo URL, hero text, payment methods on/off
- LocalStorage-এ cart/settings/last order রাখা
- Mobile responsive

গুরুত্বপূর্ণ:
এটি frontend/demo। বাস্তব customer order, stock sync, admin security এবং online payment চালু করতে backend/database ও official payment gateway/API দরকার। PIN/OTP/CVV সংগ্রহ করবেন না।

GitHub Pages:
1. GitHub-এ নতুন repository তৈরি করুন, যেমন KachePai
2. এই ফোল্ডারের index.html, style.css, script.js upload করুন
3. Repository > Settings > Pages > Deploy from branch > main / root নির্বাচন করুন
4. Save করে কিছুক্ষণ অপেক্ষা করুন
5. যে Pages URL দেখাবে সেটি খুলুন

কাস্টমাইজ:
Website খুলে নিচের ⚙️ বোতামে চাপুন। নাম, slogan, logo URL, hero text এবং payment method চালু/বন্ধ করা যাবে।
